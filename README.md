# The Season

A home-screen web app for a one-year fitness campaign, run like a football season. It reads and writes a Google Sheet through a small Apps Script web app.

- `index.html`: the whole app (styles and script inline).
- `sw.js`, `manifest.webmanifest`, icons and `fonts/`: what lets it install to the home screen and open offline.
- `apps-script/Code.gs`: the script that lives in the sheet. The token here is a placeholder; the real one is only in the deployed script and on the phone.
